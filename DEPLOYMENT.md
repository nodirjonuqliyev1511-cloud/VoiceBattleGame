# Обновление ШумParty из VS Code

Рабочая папка, подключённая к GitHub и Render: `D:\voicebattle`.
Папка `D:\AI Игры\voicebattle2` — тестовая копия. Для публикации и добавления
ведущих используйте именно `D:\voicebattle`.

## Опубликовать две игры

1. В VS Code выберите **Файл → Открыть папку** и откройте `D:\voicebattle`.
2. Откройте **Управление версиями / Source Control** (`Ctrl+Shift+G`).
3. В списке изменений будут страницы ШумParty, `server.js`, код игры с малышами,
   её картинки и библиотека QR-кода. `data/hosts.json` при этом переносе не менялся.
4. Нажмите **+** рядом с **Changes / Изменения**, чтобы включить изменения в коммит.
   Папки `node_modules`, `.local` и файл `.env` включать не нужно — они игнорируются.
5. Введите сообщение `ШумParty: две игры и новое оформление`, нажмите **Commit / Фиксация**.
6. Нажмите **Sync Changes / Синхронизировать изменения** или **Push / Отправить**.
   Одного сохранения файлов или Commit недостаточно: изменения должны попасть в GitHub.
7. Если на Render включён Auto-Deploy для этой ветки, новая публикация запустится
   после отправки. Если выключен — откройте существующий сервис Render и выберите
   **Manual Deploy → Deploy latest commit**. Новый сервис создавать не нужно.
8. Дождитесь успешного завершения деплоя, затем откройте ваш прежний адрес сайта
   с `/games.html`. При необходимости войдите заново и обновите страницу `Ctrl+F5`.

Настройки существующего Render-сервиса сохраняются. Запуск — `npm start`,
зависимости не изменились. При открытии сайта на Render QR-код использует адрес
самого сайта. Локально он использует IP компьютера в Wi-Fi или `PUBLIC_BASE_URL`,
если эта переменная задана.

## Добавить ведущего бесплатно, как раньше

1. Откройте в VS Code папку `D:\voicebattle`.
2. В терминале этой папки запустите `npm start`. Если на порту 3000 запущена
   тестовая копия, сначала остановите её в её терминале через `Ctrl+C`.
3. Откройте **локальную** админку `https://localhost:3000/admin-login.html`.
4. Войдите как администратор и создайте ведущего. Сервер сам запишет логин,
   имя ведущего и хеш пароля в `D:\voicebattle\data\hosts.json`.
5. В Source Control включите изменение **`data/hosts.json`** в коммит,
   укажите сообщение, например `Добавлен ведущий`, нажмите Commit и Push/Sync.
6. Дождитесь деплоя на Render. Новый ведущий сможет войти на прежнем адресе сайта.

Пароли в JSON вручную менять не нужно — используйте форму локальной админки.
Не копируйте `data/hosts.json` из тестовой папки поверх рабочего списка.
Если добавить ведущего только в админке публичного сайта, компьютер и GitHub его
не получат; при перезапуске/деплое изменения временной файловой системы могут исчезнуть.

## Что сохраняется

- **Ведущие:** локальный `data/hosts.json` → GitHub → Render. База данных не нужна.
- **Фото, видео и иллюстрации:** файлы проекта в `public/`.
- **Комнаты и ход игры:** только память сервера, закрытие комнаты удаляет её.
- **Записи голоса:** только временно в гонках; в игре с малышами записи нет.

Официальная документация Render: [деплой](https://render.com/docs/deploys),
[бесплатные сервисы и временная файловая система](https://render.com/docs/free).
